# DTV取得者向け銀行口座開設サポート

## 公開・回答に使う現行情報

- WALC VISA Consultingでは、DTV取得者限定で銀行口座開設サポートをオプションとして相談可能。
- 銀行口座の開設可否は、銀行・支店・申込時点の運用・お客様の状況によって異なる。
- 開設を保証しない。
- オプション料金は現時点の共通公開コンテンツで確定していないため、AIは金額を推測せずLINE相談へ案内する。
- DTVを取得していない方への銀行口座開設単体サポートは案内しない。

## 標準回答

WALCでは、DTV取得者限定で銀行口座開設サポートをオプションとしてご相談いただけます。開設可否は銀行等の判断とお客様の状況によるため保証はできません。必要書類や最新の対応状況、料金は公式LINEで個別にご確認ください。

## 禁止表現

- 「DTVでは銀行口座を開設できない」と一律に断定しない。
- 「必ず開設できる」「口座開設保証」と案内しない。
- 未確認の料金を回答しない。
