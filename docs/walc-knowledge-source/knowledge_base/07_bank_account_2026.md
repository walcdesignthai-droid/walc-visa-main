## 0. 本ドキュメントの位置づけ

**2026年4月の制度変更により、銀行口座開設ルールが大幅に変わりました。**
この変更は **複数事業マニュアルに横断的に影響**するため、共通リポジトリで一元管理します。

全マニュアルの該当箇所は、本ドキュメントを参照すること。

## 2. VISA別 口座開設可否マトリクス

### 2-1. 全VISA口座開設可否表

| VISA種別 | 口座開設 | 備考 |
|---|---|---|
| **観光ノービザ** | ✕ 不可 | 短期滞在のため |
| **TR15(VOA)** | ✕ 不可 | 15日のみ |
| **TR60(観光VISA)** | ✕ 不可 | 観光のため |
| **TR180(マルチプル観光)** | ✕ 不可 | 観光のため |
| **DTV VISA** | **△ 個別確認** | 通常開設は難しい。WALC 取得者限定オプションあり |
| **NON-B(ビジネス)** | ✅ 可能 | WP取得連動 |
| **NON-O Retirement** | ✅ 可能 | リタイア定番 |
| **NON-O 結婚** | ✅ 可能 | — |
| **NON-O 家族** | ✅ 可能 | — |
| **NON-ED(学生・大学/高度専門学校)** | ✅ 可能 | 認可大学・高度専門学校系のみ |
| **NON-ED(学生・語学/ムエタイ/調理など)** | ✕ 不可 | 私塾系の学校種別は不可 |
| **Thailand Privilege(全ティア)** | ✅ 可能 | サポート付き |
| **LTR VISA(全カテゴリ)** | ✅ 可能 | 最強カテゴリ |

### 2-2. 重要ポイント

```
★ 観光カテゴリのVISAは原則として口座開設が難しい
★ DTVは WALC 取得者限定オプションを個別確認する
★ 銀行・支店・顧客状況により異なるため、開設可否や料金を確約しない
★ 居住者向けVISA(NON-Immigrant系)は開設可能
★ Thailand PrivilegeとLTRは観光カテゴリだが、
  制度設計上、銀行口座開設サポートが組み込まれている
★ 学生VISA(NON-ED)は学校種別で可否が分かれる(下記 2-2-1)
```

### 2-2-1. 学生VISA(NON-ED)の口座開設可否(重要)

NON-ED は「学校種別」によって口座開設の可否が大きく分かれる。
顧客対応では必ず学校種別を確認すること。

| 学校種別 | 口座開設 | 備考 |
|---|---|---|
| **認可大学(学士・修士・博士)** | ✅ 可能 | 文部省認可大学・国際大学含む |
| **高度専門学校(Vocational College)** | ✅ 可能 | 政府認可の高等専門教育機関 |
| **語学学校(タイ語・英語等)** | ✕ 不可 | 私塾扱い |
| **ムエタイ学校・スポーツ系学校** | ✕ 不可 | 私塾扱い |
| **調理学校・職業訓練校(認可外)** | ✕ 不可 | 私塾扱い |
| **インターナショナルスクール(初〜高等)** | ✕ 不可 | 親の同伴 NON-O は別判定 |

**顧客対応スクリプト例**:

```
[顧客]「学生VISAで口座開設できますか?」
       │
       ▼
[WALC]「どの学校に通われる予定でしょうか?
       認可大学・高度専門学校であれば可能ですが、
       語学学校・ムエタイ・調理学校等の私塾系の場合は
       現在開設できません。」
```

**注意**: 上記は 2026 年 5 月時点の運用ベース。銀行・支店により判断が異なるケースもあるため、
最終的な可否は申請時に WALC 担当者経由で確認すること。

## 4. 各マニュアルへの影響箇所

### 4-1. DTVマニュアルへの影響

| 章 | 修正内容 |
|---|---|
| **Ch.1 DTVとは** | 「通常開設は難しい。WALC取得者限定オプションは個別確認」を明示 |
| **Ch.2 取得条件** | 影響なし |
| **Ch.7 入国後の運用** | 「WALC取得者限定オプションは個別確認」を追加 |
| **Ch.10 FAQ** | 「DTVで口座開設できる?」→「個別確認」を追加 |
| **Ch.12 最新制度情報** | 2026年4月変更として明記 |

### 4-2. リタイアメントビザマニュアルへの影響

| 章 | 修正内容 |
|---|---|
| **Ch.1 概要** | 「口座開設可能」を**強み**として訴求 |
| **Ch.3 料金** | 「銀行口座開設サポート +6,000 THB」を明示 |
| **Ch.9 強み** | 「通常開設が難しい DTV との違い」を正確に比較 |

### 4-3. Thailand Privilegeマニュアルへの影響

| 章 | 修正内容 |
|---|---|
| **Ch.1 概要** | 「口座開設可能・サポート付き」を強み訴求 |
| **Ch.9 強み** | 「銀行コンシェルジュ付」を訴求 |
| Ch.8 比較 | DTV比較欄に「口座開設可否」軸を追加 |

### 4-4. LTR Visaマニュアルへの影響

| 章 | 修正内容 |
|---|---|
| **Ch.1 概要** | 「口座開設可能」を含むベネフィットに明記 |
| **Ch.9 強み** | 税優遇 + 口座開設可 + 年次レポート で三位一体訴求 |

### 4-5. 空港サポートマニュアルへの影響

影響なし(空港サポートは入国時サービスのため口座開設と独立)。

## 5. 営業上の活用方法

### 5-0. 基本前提

```
★ 重要 ★

口座開設希望の顧客には、
まず DTV 取得者限定オプションの対応可否を確認する。

[顧客対応の判断軸]
   Q. 銀行口座開設は「必須」か「あれば嬉しい」か?
   
   ┌─ 「必須」(明確に必要)
   │       ↓
   │   DTV取得者限定オプションを個別確認
   │   対応不可なら NON-O / Privilege / LTR
   │
   └─ 「あれば嬉しい」(本当は不要)
           ↓
       DTV第一推奨を維持
       (現金主義の生活で十分なケースも多い)

→ 口座開設を理由に高額VISAを推奨することは
  顧客利益に反する場合がある。
  まず「本当に口座が必要か?」をヒアリングする。
```

### 5-1. 口座が「必須」な顧客への選択肢

```
[シナリオA] DTV保有者で口座が「必須」になった顧客
       │
       ▼
   WALC限定オプションの対応可否を個別確認
   対応不可なら NON-O / Privilege / LTR を比較
       
[シナリオB] 50歳以上で口座が「必須」
       │
       ▼
   NON-O Retirement(13,000〜72,000 THB)
   → 口座開設サポート +6,000 THB
       
[シナリオC] 富裕層で口座が「必須」
       │
       ▼
   LTR WGC or Thailand Privilege
   → 「口座開設込み」を訴求
```

### 5-2. 「DTV+口座」を希望する顧客への対応

```
[よくある質問]
   「DTV取れば口座も開けるんですよね?」

[標準回答]
   WALC では DTV 取得者限定の銀行口座開設オプションを
   ご用意しています。

   ただし、銀行・支店・お客様の状況により
   必要条件や対応可否が異なります。
   料金を含め、専門スタッフが個別に確認します。

   開設を保証せず、対応できない場合は
   NON-O Retirement / Thailand Privilege / LTR Visa
   も比較してご案内します。
```

### 5-3. 口座希望顧客への提案順序

口座開設が「必須」と確認された顧客への確認順序:

```
[第1優先] WALC DTV取得者 → 限定オプションを個別確認
   ※ 対応可否・料金は確約しない

[第2優先] 50歳以上 → NON-O Retirement(13,000〜72,000 THB)
   ※ DTV+α の予算感で最もコスパが良い

[第3優先] 富裕層・面倒回避 → Thailand Privilege
   ※ コンシェルジュ込み

[第4優先] 高所得 → LTR Visa
   ※ 専門スタッフ転送
```

#### リタイアメントビザの優位性訴求(口座希望ケースのみ)

```
[文脈] 50歳以上で口座開設が必須な顧客への提案

「50歳以上で残高80万THBがあれば、
わずか13,000 THBから(日本国内E-VISA)
口座開設可能なVISAが取得できます。

DTVをご検討中とのことですが、
お客様の場合は銀行口座が必須とのことなので、
DTVの限定オプションが対応不可の場合は、
リタイアメントビザの方がお客様の目的に合っております。」
```

## 7. 顧客対応の決め台詞集

### 7-1. 「DTVだけで口座も開きたい」への対応

```
「WALCでは DTV 取得者限定の
銀行口座開設オプションをご用意しています。

銀行・支店・お客様の状況により必要条件が異なるため、
対応可否・料金は専門スタッフが個別に確認いたします。
開設を保証するものではありませんので、
まずはご状況をお聞かせくださいませ。」
```

### 7-2. リタイア層への提案

```
「50歳以上で残高80万THB相当がございましたら、
NON-O リタイアメントが最もコスパの良い選択肢です。

たった13,000 THBから取得可能で、
口座開設サポート(+6,000 THB)も含めて
20,000 THBほどで完結します。

DTVや他VISAと比べて圧倒的に安く、
かつ銀行口座まで開けるのは
弊社の強みでもございます。」
```

### 7-3. 富裕層・面倒回避層への提案

```
「タイ移住を本格的にご検討でしたら、
Thailand Privilege か LTR Visaをおすすめします。

両方とも銀行口座開設が含まれており、
ビザの更新や90日レポートの煩雑さからも解放されます。

LTRは要件が高いですが税優遇が大きく、
Privilegeは要件不問で取得しやすいのが特徴です。

詳細を弊社の専門スタッフよりご案内させて頂きます。」
```

```
[新規問い合わせ受領]
```
